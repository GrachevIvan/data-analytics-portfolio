# Прогнозирование ежедневной нагрузки (total_actions)

## Задача
Спрогнозировать общее количество действий (просмотры + лайки) на 30 дней вперёд для планирования серверных мощностей.

## Данные
- **Источник:** ClickHouse, таблица `feed_actions`
- **Период:** 2026-05-30 – 2026-08-08 (полные дни)
- **Метрика:** `count(*)` по дням
- **Дополнительный регрессор:** `is_flashmob` (флешмоб 10–16 июля 2026)

## Инструменты
- Python (pandas, numpy, matplotlib)
- **Orbit** (модель LGT – Local Global Trend)
- ClickHouse (pandahouse)

## Методология
1. Агрегация дневных действий.
2. Выделение периода флешмоба как бинарного регрессора (чтобы модель не воспринимала аномалию как изменение тренда).
3. Построение модели **LGT** с параметрами:
   - `seasonality=7` (недельная сезонность)
   - `estimator='stan-map'` (быстрая оптимизация)
4. Бэктест на горизонте 7 дней с расширяющимся окном (min_train_len=28, шаг 7 дней).
5. Прогноз на 30 дней с доверительным интервалом (аппроксимирован через стандартное отклонение остатков бэктеста).

## Результаты
- **SMAPE на 7-дневном бэктесте:** 17.1% – модель хорошо улавливает недельную сезонность.
- Модель успешно отделяет органический тренд от аномального всплеска флешмоба.
- Прогнозная медиана показывает плавный органический рост.
- Верхняя граница 95% интервала – ориентир для пиковой нагрузки.
- Наиболее надёжны предсказания на первые **7–14 дней**; далее неопределённость растёт.

## Ограничения
- Не учтены будущие маркетинговые кампании, технические инциденты или праздники.
- Доверительный интервал аппроксимирован (не байесовский), для критических систем рекомендуется использовать полные байесовские методы.
