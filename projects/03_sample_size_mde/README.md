# Расчёт размера выборки и минимально детектируемого эффекта (MDE)

## Задача
Для планируемого A/B-эксперимента (увеличение просмотров на 1–2 с вероятностью 90% у активных пользователей) определить, достаточно ли текущей аудитории для обнаружения эффекта с мощностью 80%.

## Данные
- Исторические данные за период АА-теста: 2026-06-19 – 2026-06-25
- Эмпирические распределения просмотров и CTR на пользователя (извлечены из `feed_actions`).
- Размер выборки при равном сплите: ~21 000 пользователей (на группу).

## Инструменты
- Python (numpy, pandas, scipy, tqdm)
- Jupyter Notebook
- ClickHouse (pandahouse)

## Методология
1. Загрузка эмпирических распределений просмотров и CTR.
2. Симуляция АА-теста (проверка FPR на уровне 5%).
3. Симуляция АБ-теста с заданными эффектами:
   - **Порог 50 просмотров:** эффект применяется только к пользователям с views ≥ 50.
   - **Порог 30 просмотров:** расширение целевой аудитории.
   - **Увеличение длительности до 2 недель:** размер выборки ~30 600.
   - **Фильтрация нецелевых пользователей:** анализ только на пользователях с views ≥ 30.
4. Оценка мощности (доля значимых результатов при α=0.05) для каждого сценария.

## Результаты
| Сценарий | Мощность |
|----------|----------|
| Порог ≥50 | ~26% |
| Порог ≥30 | ~42% |
| Выборка 30 600 (2 недели) | ~56% |
| Фильтрация неактивных (views ≥30) | ~64% |

**Вывод:** даже в лучшем случае мощность не достигает 80% – необходимо либо увеличивать эффект, либо менять дизайн эксперимента.

## Рекомендации
- Увеличить длительность эксперимента или порог отбора.
- Рассмотреть альтернативные метрики (например, лайки или время сессии).
- Внедрить методы снижения дисперсии: стратификация, CUPED.
- Пересмотреть ожидаемый эффект – возможно, он завышен.
