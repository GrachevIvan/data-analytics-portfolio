# A/B-тестирование нового алгоритма рекомендаций

## Задача
Оценить влияние нового алгоритма рекомендаций на CTR пользователей в ленте новостей.  
Принять решение о раскатке на всю аудиторию на основе статистического анализа.

## Данные
- **Источник:** ClickHouse, таблица `feed_actions`
- **Период:** 2026-06-26 – 2026-07-02
- **Группы:**  
  - Контрольная (1) – старый алгоритм  
  - Тестовая (2) – новый алгоритм
- **Единица анализа:** пользователь (user_id)
- **Метрика:** CTR = likes / views (на пользователя)

## Инструменты
- Python (pandas, numpy, scipy, matplotlib, seaborn)
- ClickHouse (pandahouse)
- Jupyter Notebook

## Методология

1. **Загрузка и первичный анализ**
   - Проверка размера групп, средних значений, глобального CTR.
2. **Визуализация распределений**
   - Гистограммы, boxplot, KDE для визуального сравнения.
3. **Статистические тесты**
   - **t-тест Уэлча** (сравнение средних)
   - **Тест Манна-Уитни** (сравнение медиан)
   - **Пуассоновский бутстреп** для разницы глобальных CTR
   - **Сглаженный CTR** (α=5) с последующим t-тестом
   - **Бакетное преобразование** (50 бакетов) с t-тестом и Манна-Уитни
4. **Интерпретация результатов и бизнес-рекомендации**

## Результаты

- **Контрольная группа:** средний CTR = 0.2097  
- **Тестовая группа:** средний CTR = 0.2003  
- **Абсолютное падение:** –0.0094 (**–4.5%**)

### Ключевые выводы
- Распределение CTR в тестовой группе оказалось **бимодальным**:
  - Большая часть пользователей показала значительное падение CTR (левый пик).
  - Небольшая часть – аномально высокий CTR (правый пик).
- Бакетные тесты и Манна-Уитни дали p-value < 1e-8 – падение статистически значимо.
- Пользовательские t-тесты и бутстреп не показали значимости из-за сильной бимодальности.

## Бизнес-решение
**НЕ раскатывать алгоритм на всех пользователей.**

### Рекомендации
1. **Немедленный откат** – вернуть контрольный алгоритм 100% трафика.
2. **Пост-мортем** – разделить тестовую группу на сегменты:
   - CTR < 0.15 (пострадавшие)
   - CTR > 0.3 (аномально успешные)
   - Проанализировать их портреты (ОС, регион, интересы).
3. После исправления причин рассмотреть адресное внедрение только для узкой аудитории, показавшей рост.
