# Дашборды в Superset

В этой папке собраны скриншоты дашбордов, разработанных для мониторинга ключевых продуктовых метрик.

## Содержание

1. **Лента новостей – основные метрики**
   - DAU, WAU, MAU
   - Динамика лайков и просмотров
   - CTR по дням
   - Топ постов по лайкам, CTR и охвату
   - Аудитория по возрасту и городам

2. **Лента новостей – оперативные данные**
   - Почасовые события и CTR с наложением недельного смещения
   - Фильтры по ОС, полу, ID поста

3. **Взаимодействие двух сервисов (лента + сообщения)**
   - Сегментация аудитории: только лента, только сообщения, оба
   - Разбивка по полу

4. **Анализ оттока пользователей**
   - Сравнение 17 и 18 июля 2026 по странам, возрастным группам, полу, источнику
   - Выявлена аномалия: почти все пользователи из России пропали 18 июля (с 14 216 до единичных значений)

5. **Ретеншн рекламной кампании**
   - Когортный анализ пользователей, пришедших по рекламе (9 июля 2026)
   - Удержание падает до ~4% на 2-й день и держится на уровне 3–4% – реклама привлекла нерелевантную аудиторию

## Инструменты
- **Apache Superset** – построение дашбордов
- **ClickHouse** – источник данных

## Результаты
Дашборды помогают быстро отслеживать аномалии, анализировать поведение пользователей и принимать решения по продукту. На основе дашборда по оттоку был оперативно выявлен сбой 18 июля, локализованный в России.
